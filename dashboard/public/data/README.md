# Map data

`ne_110m_admin_0_countries.geojson` is the Natural Earth 1:110m Admin 0 Countries dataset, downloaded from the project's official repository:

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
- Product page: https://www.naturalearthdata.com/downloads/110m-cultural-vectors/110m-admin-0-countries/
- Retrieved: 2026-08-25
- SHA-256: `6866C877D39CBA9C357620878839B336D569F8C662D3CFAB4CB1DBE2D39C977F`

Natural Earth is public domain. The dashboard uses these country boundaries only as a local basemap; article pins come from the separately validated CrisisPulse training report.
